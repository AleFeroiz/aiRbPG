# Sistema de reservas para espaço de RPG de mesa

Projeto acadêmico da disciplina Linguagem de Programação VIII. A proposta é criar um aplicativo desktop para administrar os ambientes e os aluguéis por horário de um espaço preparado para sessões de RPG de mesa.

> Nome de trabalho: **Dados & Dragões**. O grupo ainda pode escolher outro nome.

## Direção técnica

- C# e Windows Forms no Visual Studio.
- SQL Server para persistência.
- Aplicativo desktop para uso administrativo.
- Escopo e decisões iniciais: [`docs/visao-geral.md`](docs/visao-geral.md), [`docs/requisitos.md`](docs/requisitos.md), [`docs/modelo-dados.md`](docs/modelo-dados.md) e [`docs/plano-de-implementacao.md`](docs/plano-de-implementacao.md).

Preparação e planejamento. Ainda não há código de aplicação nem banco implementado. A versão do .NET, a edição/forma de instalação do SQL Server e detalhes de avaliação devem ser confirmados com o professor e o grupo antes de iniciar a implementação.
